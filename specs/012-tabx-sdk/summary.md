An app built from this template is told who is calling and nothing else, so a screen that needs the list of departments, or a colleague's details, has no way to ask even though the platform already holds all of it. This adds a deliberately narrow client for that platform: six read-only lookups, no writes, and no general-purpose escape hatch, so adding a seventh is an edit somebody makes on purpose rather than something that happens by accident. The credential it uses is the person's own, arriving with the request, so the app reaches exactly what they can reach and nothing more. Two rules keep that credential contained, and both are checked automatically: it is never attached to the identity object services pass around, and exactly one file in the app may read it. The client ships working but unused, ready for the first app that needs it.
