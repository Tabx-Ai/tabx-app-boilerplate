Until now every person using a generated app could do everything in it. The platform decides who may open an app at all, but inside it there was no way to say that one action belongs to a manager and another to everyone. This spec adds that in one place: a single folder holds every rule in the app, each a named check written against the identity the platform already sends, so a rule can ask about someone's role, their department or their manager without looking anything up. The rules ship open, allowing everyone, so an app tightens one by editing it rather than inventing a mechanism. The server always checks before it acts. The interface gets a wrapper that hides anything the person may not do, and it asks the server what those are rather than deciding itself, so the two cannot disagree.
