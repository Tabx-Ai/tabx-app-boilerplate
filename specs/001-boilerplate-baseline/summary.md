This record says what this app starts out containing. The backend is a single serverless function: every request arrives as one small envelope naming the path, method, query and body, and an internal router hands it to the right service. The platform validates every caller before the request arrives, so the app never checks a password or token itself — a request without the platform's identity attached is simply refused. The frontend is a React foundation trimmed to essentials, talking to the backend through one client that carries a pass token held only in memory. Configuration is read once, in one place, and a missing setting fails loudly by name. A sample service and a sample page prove the whole chain end to end, and a manifest file records exactly what the platform has granted this app.
