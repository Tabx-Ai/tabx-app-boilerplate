Most apps built from this template are one screen and need no navigation. Those that do had no agreed shape, so each would invent its own. This spec supplies the shape the platform itself uses: a narrow strip of icons for the main areas, and a second, wider list of destinations belonging to whichever area is open. Both are built and tested here but deliberately wired to nothing, so no existing screen changes and an app adopts them only if it needs them. The value is in three details that are easy to get wrong and give no error when they are: where the second list sits relative to the page content, how the current item is highlighted without lighting a parent too, and how two lists on one screen are announced distinguishably to a screen reader. The rule for using them is written into the template's governing document.
