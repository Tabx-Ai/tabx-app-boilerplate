This is the back half of the app: a single function that receives a request as a small package of data and answers with another, not a web server on a port. The most important promise it makes is that nothing can escape it. An address nobody serves, a badly formed request, a mistake in the code: each becomes a proper answer with a status, because a function that crashes is retried by its caller, and a retried action is one nobody asked for twice. Who is calling is decided by the platform and handed in; one file reads that and refuses anything without it, so no part of the app ever sees an anonymous user. Settings are read once, in one place, and everything has a default so a fresh copy runs immediately. A small local helper lets a developer drive the whole chain with nothing else running.
