Before either half of this app has code, its ground rules are settled: what it is built on, where things live, and what it is called. The backend and the frontend are two separate projects that install themselves, so neither can quietly borrow something the other declared. They deliberately share no package between them, because this app has to build on its own from a plain copy, and a shared one would break that the moment somebody tried. The libraries it uses are written down in three lists per project: what ships, what a change may add and why, and what is refused. The app's own name and description live in one file the platform fills in, so nothing else names it. Finally, the three places that describe its settings are checked against each other by a test, because a drift between them is a deploy that silently misses one.
