The app's front half did not know where its own back half was. It sent every call to a local address that existed only while a developer ran a helper, so an app built from this could not talk to anything once deployed. This spec teaches it to work that out for itself: an app served at one address calls its backend at the matching one, and locally it falls back to a path the developer's helper answers, so the same code runs in both places. Calls become ordinary web requests rather than a hand-assembled package, because the platform's gateway already assembles that itself and a pre-built one would have described the wrong call. Each area of the backend gets two small files on this side: one listing its addresses, one holding the typed calls. No screen writes an address or reaches the network directly, and tests hold both rules.
