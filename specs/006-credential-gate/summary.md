An app opened from the workspace arrives with a one-time pass in its address, and that pass used to survive only until the page was refreshed. Because the address is deliberately cleaned afterwards, a refresh left the user stuck with no way back in. This spec adds a proper door. The app opens at a dedicated entrance which checks the pass with the platform first, keeps it for the life of the tab, then sends the user into the application proper, which now lives under its own path. Anyone arriving without a valid pass sees one clear screen telling them to open the app from their workspace. If the platform later withdraws a pass, the next refused request clears it and shows the same screen, while a request refused for any other reason leaves the pass alone, because being told no is not the same as being logged out.
