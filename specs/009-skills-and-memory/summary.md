Five earlier changes altered how this app is built, and each of them carefully updated the rules: the governing document, the list of libraries, the notes. None of them updated the short guides an assistant actually reaches for while writing code. So the guides and the rules disagree, and the guides do the damage, being closer to the keyboard. One of them still tells you to register a route in the shared file, which a test now rejects; another still explains how to add a dark mode this app has decided not to have. This spec brings all four guides back in line, deletes the dark-mode material outright, and checks each guide by following it literally to see whether the result passes the app's own tests. It also records why this happened, so the next change updates both kinds of document rather than only the one that governs.
