This app was already built around a single light appearance, but it still carried a second, dark set of colours inherited from a platform's public marketing page, which an app like this has no equivalent of. It also carried three leftovers pointing at a dark mode that does not exist: a chart helper referencing a missing style, a loading indicator with a variant nothing used, and a comment on the button describing a colour switch that never happens. All four are removed, and nothing about the light appearance changes: the colour definitions come out of the change untouched, which the spec proves rather than promises. Two small tests are added so the rule holds afterwards, because adding a component from the usual generator quietly reintroduces dark styles, which has happened before. Each test was watched failing before being trusted. The rule is also written into this app's governing document.
